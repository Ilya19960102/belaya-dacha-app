# Таблица результатов и коды доступа

1. Создай Google Таблицу (например, «Белая Дача — результаты тестов»).
2. В таблице: **Расширения → Apps Script**. Удали всё в редакторе, вставь содержимое `Code.gs`, сохрани.
3. **Начать развертывание → Новое развертывание** → шестерёнка → **Веб-приложение**.
   - Выполнять от имени: **меня**
   - У кого есть доступ: **Все**
4. Разреши доступ, когда Google спросит, и скопируй **URL веб-приложения** (заканчивается на `/exec`).
5. Вставь его в `config.js` в `SHEETS_URL: '...'` и загрузи `config.js` в репозиторий.

После этого в таблице появятся листы «Результаты» и «Запросы кода». В «Запросах кода» сразу виден
4-значный код, который нужно сообщить сотруднику. Код для любого номера можно получить формулой `=КОД(B2)`.

Проверка: телефон +7 900 123-45-67 → код **4634**.

Если меняешь `CODE_SALT`, поменяй `SALT` в `unlock.js` на тот же — иначе коды не подойдут.
